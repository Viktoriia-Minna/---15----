# Пошук країн

Невеликий Parcel-додаток для пошуку країн через Rest Countries API v5. Пошук
починається через 500 мс після введення; список до 10 результатів або картка
країни з'являються під полем пошуку.

## Запуск

```sh
npm install
cp .env.example .env
# Вкажіть свій ключ у REST_COUNTRIES_API_KEY у файлі .env
npm start
```

Створіть ключ на [restcountries.com](https://restcountries.com/sign-up) і
додайте адресу застосунку до дозволених origins налаштувань ключа. Для Parcel
за замовчуванням це `http://localhost:1234`. Ключ вбудовується у клієнтський
код, тому використовуйте ключ з обмеженням за origin та не публікуйте файл `.env`.

## Перевірка та production-збірка

```sh
npm test
npm run build
```

Production-файли створюються в `dist/`; цю папку можна опублікувати на GitHub
Pages.

> Rest Countries API v1–v4 виведені з експлуатації. Застосунок використовує v5,
> Bearer-автентифікацію та нову структуру відповіді.
